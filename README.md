# tiyatroberlin.de

Tiyatro Berlin'in web sitesi. Eleventy ile üretilir, GitHub Pages'te yayınlanır.

- İçerik: `src/_data/` (oyunlar `works.yaml`, metinler `texts.yaml`, kişiler ve mekânlar `db.yaml`, bio'lar `bios.yaml`, program dışı etkinlikler ve kurslar `extras.yaml`, sayfa metinleri `pages.yaml`)
- Görseller: `src/assets/img/` (raster işlenmiş)
- `main` dalına her gönderimde site yeniden yayınlanır; her gece de bir kez kendiliğinden yenilenir.
